# 12 个剖析动作 · 深度分析与内化

> 来源: 卡兹克《都 Agent 时代了，我还是想分享给你这 12 个我最常用的 Prompt》（2026-08-21）
> 升级目标: 从「可粘贴的提示词模板」内化为「本 Agent 默认的剖析思考动作」——先定位场景、用对应方法思考，再决定执行路径。
> 对应 skill: prompt-dozen（模板库）+ 12 个独立 skill。

## 总论：12 个动作的底层逻辑

这 12 个方法本质上是一套完整的「认知操作系统」，覆盖了从混沌到行动的整条链路：

1. 人脑默认是混乱的 → 需要「问清问题」先收敛
2. 认知有四种缺口 → 需要「学习」四法补齐
3. 问题有共性结构 → 需要「解决」三法拆解
4. 信息够了但犹豫 → 需要「决策」两法定夺
5. 方向和自我不明 → 需要「认识自己」两法锚定

**内化方式**：不是每次对话都套模板，而是把这 12 个方法变成我的思维肌肉——遇到对应场景，先按该方法的框架思考，再选择工具执行。模板是完整形态，思考动作是日常形态。

## 一、问清问题（先澄清再答）

### 1. 苏格拉底式提问 → 对应 skill: socratic-questioning

- **本质**: 用户嘴上问的和心里真正想表达的往往不一致；通过 ≤6 个追问，把「表层问题」收敛为「真正值得回答的问题」。
- **触发信号**: 用户问题含糊、混乱、自相矛盾；或用户带着情绪提问；或问题太大无从下手。
- **思考动作**:
  1. 先区分：可验证的事实 / 对事实的解释 / 价值判断 / 想实现的目标；
  2. 检查：关键词是否含糊？默认了哪些前提？证据来源？有无相反解释？
  3. 只问可能改变结论的问题，信息足够就停；
  4. 输出：原始问题 → 真问题 → 已确认事实 → 未验证假设 → 关键变量 → 可行动的新问题。
- **日常用法**: 任何需求进来，先自问「这是真问题吗？用户真正想要的是什么？」，必要时用 1-2 个澄清问题确认，而不是直接执行。

## 二、学习（四种认知缺口）

### 2. 双层解释法 → 对应 skill: dual-layer-explanation
- **本质**: 解决「好像懂了但机制不清」。类比只给人「懂的感觉」，双层解释同时给直觉（小白层）和机制（专业层）。
- **触发信号**: 讲陌生概念/技术名词；用户说「帮我学习 X」；代码里出现看不懂的库/协议。
- **思考动作**: 小白层（生活化比喻+例子）→ 专业层（准确术语+机制+边界+常见误解）→ 术语对照 → 易错点 → 3 个自测题。

### 3. 反向拆解 → 对应 skill: reverse-decomposition
- **本质**: 从优秀成品逆向学「为什么有效」，而不是羡慕结果。
- **触发信号**: 用户说「这个做得真好，我想学」；分析优秀产品/网页/方案/流程。
- **思考动作**: 一句话说它解决什么问题 → 服务谁/目标 → 结构/流程 → 哪些关键选择拉开差距 → 完成标准 → 可迁移规律 vs 案例专属细节 → 提炼 3-5 条可复用规律 + 操作清单 + 最小练习。

### 4. 横纵分析法 → 对应 skill: cross-axis-research
- **本质**: 深度研究任何陌生领域的两条轴：纵轴（历史演化：怎么走到今天）✕ 横轴（横向对比：今天与竞品有何差异）。两轴交叉才能看见「历史上的选择如何变成今天的能力/包袱」。
- **触发信号**: 半小时搞懂陌生领域；研究产品/公司/人物/技术/行业/事件。
- **思考动作**: 纵向（诞生背景/关键推动者/转折/早期选择的影响）→ 横向（选最值得比的对象/统一维度对比/用户为何选它为何放弃）→ 合轴（路径依赖如何影响未来/3 条可能路径/前提与预警信号）→ 证据规则（一手来源/标注来源/事实推断观点分开/冲突并列）。
- **产出**: 核心结论、关键时间线、横向对比表、详细分析、未来判断、待确认问题。

### 5. 事实核查 → 对应 skill: fact-check
- **本质**: 人类和 AI 都会「愚昧之巅」；先怀疑一切，再分级标记可信度。
- **触发信号**: 用户转发观点/数据/结论；信息源不明；需要判断「这说法能不能信」。
- **思考动作**: 拆成 事实/结论/价值判断 → 事实部分联网核实（已证实/基本成立/有争议/证据不足/明显错误）→ 在假设事实成立下检查推理链（能否推出结论/隐藏假设/因果混淆/遗漏解释/成立条件）→ 输出：可信与需修正处、推理链最关键的漏洞、补强后的最合理版本、可信度评估。

## 三、解决问题（三种拆解路径）

### 6. 专家会诊 → 对应 skill: expert-panel
- **本质**: 复杂问题常属多个专业交叉；让 AI 组 3 个真正互补的视角互相挑战——真正的信息往往在分歧里。
- **触发信号**: 复杂问题、多维度决策、单一视角搞不定。
- **思考动作**: 选 3 个互补视角（说明各自必要性）→ 各自回答（重新定义问题/推荐路径/其他视角易忽略的风险/什么新证据会改变判断）→ 互相质疑（共同认可的事实/真正分歧/分歧背后的假设）→ 综合输出（推荐方案/适用条件/最大风险/退出条件/第一步行动）。

### 7. 第一性原理 → 对应 skill: first-principles
- **本质**: 路径依赖时，抛开惯例，从基本事实/目标/约束重新推导。
- **触发信号**: 方案打满补丁仍不行；改组织流程/产品架构/复杂系统；Vibe Coding 陷入僵局。
- **思考动作**: 拆回底层（已确认的基本事实 / 习惯接受但未验证的假设 / 真正目标 / 资源约束）→ 放下行业惯例重新推导 → 输出（原方案只在修补表面的部分 / 新路径 / 成立前提 / 验证第一步）。

### 8. 跨领域借解 → 对应 skill: cross-domain-solution
- **本质**: 第一性原理是回到本质，跨领域借解是向外扩散——你的问题可能在其他行业已被解决十几年。
- **触发信号**: 本行业第一性原理走不通；需要创新视角。
- **思考动作**: 剥掉行业术语抽象底层结构 → 找核心矛盾 → 从 3 个以上遥远领域找结构相似问题（各领域问题/解决机制/相似点/可迁移部分/失效条件）→ 选 3 种机制翻译回当前处境 → 推荐一个低成本可逆实验。

## 四、决策（两种定夺路径）

### 9. 双向钢人论证 → 对应 skill: steelman-argument
- **本质**: 两个选项都有道理时，把各自「最强论证」摆全（不是 strawman 打击），找出真正分歧与关键变量。
- **触发信号**: 犹豫不决；两个方案都有道理；需要做重要选择。
- **思考动作**: 重述真正需要做的选择 → 双方最强理由/适用条件/最大收益/最大风险/最难回答的反对意见 → 找真正分歧/最可能改变结论的变量/还缺的信息 → 只问一个最可能改变结论的问题 → 等回答后再给判断。

### 10. 最小实验 → 对应 skill: minimal-experiment
- **本质**: 纸上谈兵不会更清晰时，迈出第一步用现实反馈验证最关键假设。
- **触发信号**: 决定悬而未决；需要现实数据；想法停留在空想。
- **思考动作**: 找出决定背后最需要验证的 3 个假设 → 选最可能改变结论的那个 → 设计低成本可逆实验（做什么/投入/观察指标/什么结果支持继续/什么结果提醒停止/实验后获得什么新信息）→ 给出明天就能开始的第一个动作。

## 五、认识自己（两种自我锚定）

### 11. 天赋挖掘 → 对应 skill: talent-mining
- **本质**: 天赋是可迁移的底层能力，藏在怪癖、缺点、嫉妒、无意识胜任区和能量模式里；反宿命论。
- **触发信号**: 用户想找人生天赋；自我怀疑「我好像没啥天赋」。
- **思考动作**: 盖洛普/心流/荣格框架，苏格拉底式多轮追问（≤10 个主问题，4 条主线：童年废寝忘食/无意识胜任区/能量审计（回血 vs 抽干）/嫉妒对象）→ 输出万字《个人天赋使用说明书》（底层天赋+经历链/阴影面/能量地图/最佳环境/工作方式与职业方向/30 天低成本实验）。

### 12. 人生设计术 → 对应 skill: life-design
- **本质**: 人生是设计问题；先看清位置（你在这里）→ 指南针（工作观/人生观）→ 寻路（心流/能量）→ 摆脱困境（锚问题）→ 生成三个五年人生版本（奥德赛计划）→ 原型行动。
- **触发信号**: 用户问「接下来往哪去」；人生迷茫；重大方向选择。
- **思考动作**: 四阶段多轮对话（每轮只问一个问题）→ 区分重力问题与可设计问题 → 输出 8000-12000 字《个人人生设计蓝图》（四个仪表盘/真问题/指南针/能量地图/三个奥德赛计划/原型行动清单/失败免疫）。

## 如何把这套动作嵌入日常工作流

1. **每次会话开始**：core-framework 激活 → 四铁律 + 12 动作索引在脑中待命。
2. **收到任务**：先做「场景定位」——这个任务属于哪个场景（问清/学习/解决/决策）？用哪个剖析动作切入？
3. **剖析后执行**：剖析思考靠框架本身（不依赖工具），执行时才调具体工具。
4. **模板 vs 动作**：日常用「思考动作」形态（快、轻）；用户需要完整输出（深度研究/天赋说明书/人生蓝图等）时用「模板」形态（加载对应 skill）。
5. **沉淀闭环**：用过的剖析动作遇到新坑 → 回写对应 skill 的 pitfalls；发现新的可复用模式 → 新增 skill。

# FDE 全生命周期指标中枢(运营度量层)

> 本文件是 FDE 全生命周期**运营门**的度量中枢。它与 `scorecard.md`(决策门:Go/Hold/No-Go 打分)**正交**——scorecard 回答"这项目该不该签、能不能上生产"(事前),本文件回答"做得怎么样、价值有没有持续、团队还能不能走远"(事后)。**决策门不对运营门套 Go/No-Go,运营门也不重新发明一套"及格就上线"的打分**——两类门性质不同,别混。

## 🎯 为什么需要单独的指标文件(两类门,别混)

FDE 模式最反直觉的一点:**签下单、上了线,都不是终点**。

- **决策门**(scorecard,事前):用 35/20/30/15 权重打分,判 Go/Hold/No-Go。它管"这仗该不该打、能不能上生产"。
- **运营门**(本文件,事后):用四层指标度量健康度、NRR、复用率。它管"打完之后,系统有没有真被用、价值有没有持续、生意有没有变好、团队有没有累垮"。

> **关键认知(防逻辑断裂):** scorecard 的 Go 是运营门的**入场券,不是终点**。一个评分 Go、上了生产的项目,完全可能因为激活失败、价值蒸发、成本反噬而最终 NRR<100%。运营门**不对 Go/No-Go 打分**——它不给"上线/不上线"的判罚,只给"现在哪里在生病、该往哪个方向干预"的读数。

这套指标体系真正服务三件事:**① 续约谈判桌上的弹药**(被数据武装的续约 vs 凭感觉的续约,成交率不在一个量级);**② 模式是否成立的体检仪**(毛利率在不在涨、定制在不在递减);**③ 团队能否走远的预警**(续航红灯烧干团队,前面所有指标都是烟花)。

## 📐 四层指标体系总表(本文件命根子)

指标贵精不贵多——**每个客户项目盯 3 到 5 个核心指标,胜过铺满一面墙的仪表盘**。

| 层 | 回答的问题 | 代表指标 | 及格线(不达标=生病) | 优秀线(达标=模式成立) | 谁认账 |
|---|---|---|---|---|---|
| **交付层** | 项目做得对不对 | TTV / 评估达标率 / 缺陷逃逸率 | 完整部署 TTV≤4 个月;缺陷逃逸率可控 | MVD 验证 2-6 周;部署周级高频低回滚 | 工程团队 |
| **客户层** | 客户活得怎么样 | 激活率 / 健康度评分 / 支持者覆盖 | 激活率高于行业四成警戒线;健康分不跌破线 | 关键功能稳定渗透;支持者≥3 点成网 | 客户业务方 + 支持者 |
| **商业层** | 生意值不值 | NRR / 交付毛利率 / 定制递减率 | NRR≥100%;毛利率不下降 | NRR≥120%;毛利率→60%+;定制持续递减 | 客户财务 + 己方管理层 |
| **组织层** | 团队能不能走远 | 现场到产品回流速率 / 资产复用率 / 团队续航 | 复用率逐季不退;无倦怠红灯 | 复用率持续上升;人均产能抬升 | 己方管理层 |

> **读这张表的方式:** 及格线不是"达标就放心",是"低于此线说明正在生病,要查第 7 节的诊断动作"。优秀线才是模式真正成立的信号——尤其是**毛利率涨得快不快**(比绝对值高低更能说明问题)和**NRR**(总裁判,>120% 才算增长引擎内生)。

## 交付层:项目做得对不对

> 来源:附录 A 交付层。技术层(实验追踪/模型回滚/监控告警)的工程合格标准见 `mlops-playbook.md` P0 三件套,本层只看**价值与速度的读数**。

| 指标 | 定义 | 参考标准 / 红线信号 |
|---|---|---|
| **TTV(Time to Value)** | 从进场到客户获得第一次可衡量价值的时间 | MVD 验证以**周计**(2-6 周),完整部署以**月计**(1-4 个月)。**TTV 持续变长 = 方法论或平台底座出问题的第一信号**。 |
| **概念验证转化率** | 验证项目进入付费部署的比例 | 早期 5-10% → 训练营模式约 75%。**过低 = 进场筛选失职;过高(接近 100%) = 只接没有挑战的单,要警惕**。 |
| **评估达标率** | AI 输出通过业务评估集的比例 + 生产环境时间序列走势 | 生产环境**达标率走低 = 质量漂移报警器**(业务在变、模型在更新,信任随之塌方)。 |
| **部署频次与回滚率** | 迭代速度的硬指标 | 健康部署期保持**高频小步**(周级甚至日级),回滚率低而稳定。 |
| **缺陷逃逸率** | 上线后才被发现的缺陷占比 | 测的是**测试与评估体系的完备性**,不是工程师水平。逃逸率高 = 评估体系有洞。 |

> **与 scorecard 的关系:** scorecard 阶段三评"有没有实验追踪/回滚/监控"(0/1/2 有无),交付层评"这些基建跑起来后,TTV/达标率/逃逸率读数是多少"。前者是事前资格,后者是事后成绩。

## 👥 客户层:客户活得怎么样

> 来源:附录 A 客户层 + 第 5 章 5.6 健康度。信号组合判读与触发动作的展开见 `renewal-and-expansion-playbook.md`「健康度四类信号」。

| 指标 | 定义 | 参考标准 / 红线信号 |
|---|---|---|
| **激活率** | 目标用户群中形成稳定使用习惯的比例 | ⚠️ **分母是「目标用户群」,不是「系统账号数」**(账号开了一堆没人用,是假活)。MIT 报告:仅约四成企业给员工官方 AI 订阅——**激活率长期低迷 = 部署名义活着,实际死了**。 |
| **使用深度** | 关键功能几成人在用 + 频次分布(打卡式 vs 工作流嵌入)+ 自助探索行为 | **自助探索(用户自己发现新用法)是最珍贵的信号**——说明系统开始长进客户组织。只有打卡式使用 = 没真嵌入。 |
| **健康度评分** | 使用/价值/关系/商业四类信号合成 | 关键纪律:**每周全量巡视**,跌破警戒线就**自动触发干预流程**(不是季度才看)。详见 renewal 唤醒三级。 |
| **支持者覆盖数** | 客户组织内活跃盟友的数量与层级分布 | **单点是高危,三点成网**。只有一个支持者 = 续约一旦他离场就悬(企业黑话:"支持者一动,合同就悬")。 |
| **NPS(慎用)** | 净推荐值 | 企业场景参考价值**有限**(样本小、政治化)。更可靠替代:**续约意向提前问询**——到期前两个季度,直接问支持者"如果今天续约,你会续吗"。 |

> **客户层是续约的命脉:** 一个系统可以交付层全绿(质量好、速度快),却因为客户层全红(没人用、支持者要走)而续约失败。**交付层只证明"东西做对了",客户层才证明"东西做成了"**。

## 💼 商业层:生意值不值

> 来源:附录 A 商业层 + 第 6 章。这是 FDE 模式是否成立的**总裁判层**。

| 指标 | 定义 | 参考标准 / 红线信号 |
|---|---|---|
| **NRR(净收入留存)** | 存量客户收入的年度变化(含流失/降级/扩容) | **及格 100%,优秀 120%**。>120% = 增长引擎已内生(不签新单存量也在涨)。**<100% = 价值蒸发**,必查五类流失。Palantir Q4'2025 = 139%。 |
| **交付毛利率** | 单客户收入 − 交付直接成本(人力/差旅/云) | 纯人力期 20-40%,平台复用度上来→60%+。**涨得快不快,比绝对值高低更能说明模式成不成——不上升的 FDE,是咨询公司。** |
| **定制递减率** | 第 N 个客户的定制工作量 vs 第 1 个 | 麦格鲁试金石:**应显著递减**。**连续三个客户定制量不降 → 立即检视产品回流机制**(详见 scaling 三级杠杆)。 |
| **销售周期** | 首次接触到签约的时间 | 训练营把它从 9-12 个月压到数周。是获客效率与信任资产厚度的综合读数。 |
| **CAC 回收期** | 获客成本(含免费验证投入)通过合同毛利收回的时间 | FDE 模式前期普遍难看,关键是看它**随案例积累而缩短的趋势**。 |
| **LTV/CAC** | 客户终身价值与获客成本之比 | 健康线一般 ≥3。FDE 模式获客成本前置,早期可能 <2,**必须配合 NRR 一起读才有意义**。 |

> **💀 致命场景:** NRR<100% 却还在猛冲新客户——这是"漏水的桶里加水"。新客掩盖不了存量流失,等新客增长放缓,真实健康度才会暴露。NRR 是总裁判,必须纳入**季度复盘**,不是年底才看。

## 🏛️ 组织层:团队能不能走远

> 来源:附录 A 组织层 + 第 7 章。**前三层再漂亮,这一层烧干,前面所有指标都是烟花。**

| 指标 | 定义 | 参考标准 / 红线信号 |
|---|---|---|
| **现场到产品回流速率** | 单位时间内从现场沉淀为组件/平台能力的产出数(组件入库数 / 手册更新数 / 平台化提案数) | 测的是 FDE 模式的**「灵魂器官」是否还在跳动**。回流速率归零 = 你在做人天生意,不是 FDE。 |
| **交付资产复用率** | 新项目中复用已有组件/模板/清单的比例 | 三级复制杠杆的综合读数,**目标应该逐季上升**。 |
| **FDE 人均产能** | 每名前置部署工程师支撑的年收入 | 规模化的总账。纯人力模式天花板明显,平台化后应持续抬升。 |
| **团队续航指标** | 出差强度(月出差天数)/ 值班负荷 / 离职率与倦怠预警 | Reddit 上 FDE 从业者最大吐槽点就是差旅与续航。**团队烧干了,前面所有指标都是烟花。** |

> **组织层是 FDE 的隐藏成本:** 桑卡尔那段保密室两周驻场"每天 19 小时、电话绑在头上"成就了传奇,但他说"这不可持续,我们完了"——卡普的答案是"把这种不可持续做成制度"。制度化的意思不是继续压榨,是**用三级杠杆(知识/组件/产品)把不可复用的现场苦活,变成可继承的组织资产**,让下一支团队不必重走一遍。

## 🔗 指标→诊断→动作 映射表(四个运营 playbook 的总枢纽)

这张表是本文件与 `activation-playbook` / `renewal-and-expansion-playbook` / `scaling-playbook` 的接口。**每个红灯信号都有对应的诊断与动作,不靠感觉。**

| 红灯信号 | 诊断 | 动作 | 详见 |
|---|---|---|---|
| TTV 持续变长 | 方法论或平台底座出问题 | 排查 MVD 是否跑偏 / 平台底座缺件 | `activation-playbook` + `production-architecture.md` |
| 激活率 < 行业警戒线 | 系统名义活着实际死了 | 降低使用门槛四手法 / 重新选场景 | `activation-playbook` |
| 评估达标率生产环境走低 | 质量漂移 | 重过 eval / 查数据漂移 / 触发护栏 | `mlops-playbook.md` 四层监控 |
| 健康分跌破警戒线 | 关系变质 / 价值蒸发前兆 | 启动唤醒三级响应(轻/中/重) | `renewal-and-expansion-playbook` |
| **NRR < 100%** | **价值蒸发(五类流失之一发作)** | 排查流失类型(蒸发/离场/漂移/反噬/戒断)对症处置 | `renewal-and-expansion-playbook` 五类流失表 |
| 毛利率长期不上升 | 还在做人天生意(咨询公司) | 检视平台回流 / 走三级杠杆 | `scaling-playbook` |
| 定制量连续三个客户不降 | 产品回流机制失效 | 走产品化四问 / 建组件库 | `scaling-playbook` |
| 复用率逐季不升 | 三级杠杆没转起来 | 先沉淀打法手册 + 组件(一级→二级) | `scaling-playbook` |
| 支持者离场 / 单点依赖 | 续约高危 | 关系网格化 + 离场做成仪式 | `renewal-and-expansion-playbook` |
| 团队续航红灯(出差/倦怠) | 团队快烧干 | 重新分配 / 自动化交付苦活 / 补人 | `scaling-playbook` 交付自动化四类资产 |

## 📋 使用建议:每客户锁 3-5 个核心指标

1. **每个客户项目锁定 3-5 个「核心指标组合」**——通常是一个价值指标 + 一个使用指标 + 一个关系指标。铺满一面墙的仪表盘 = 没有指标。
2. **基线数据在项目启动第一天采集**——没有改造前的数据,就没有改造后的价值证明。**基线只在项目启动那一刻存在,错过永不再来。**
3. **指标必须与客户共建、双方共认**——他不认的指标,算出花来也在续约谈判桌上没有效力。立项会上达成一致的那一刻,指标就成了你们的共同语言。
4. **每半年检修一次指标体系本身**——删除无人看的,补上反复被问的。指标会腐烂。

> **价值度量系统的四层用途(第 6.7 节):** 对客户=续约扩容的证据库;对公司=交付质量体检仪;对产品=回流情报放大器(哪个功能价值产出最高/哪个无人使用);对市场=信任营销的素材库。**案例营销的最高境界不是讲故事,是亮数据;而数据不会在谈判桌上凭空出现,它在交付的第一天就要开始采集。**

## ✅ 检查清单

- [ ] 四层指标体系已定义,且客户认账其中的**业务层 + 价值层**(不是只认技术 benchmark)。
- [ ] 每客户锁定 3-5 个核心指标(典型:1 价值 + 1 使用 + 1 关系)。
- [ ] 业务层与质量层的**及格线**已书面锁定(不只是 benchmark,是客户认可的目标值)。
- [ ] **NRR 纳入季度复盘**,不是年底才看(NRR 是总裁判)。
- [ ] 组织层至少有 1 项可度量(复用率 / 回流速率 / 续航预警)。
- [ ] 每个红灯信号都有对应的诊断→动作映射(查第 7 节,不靠感觉)。
- [ ] **决策门与运营门没有混用**——没有对"健康度"套 Go/No-Go 打分,也没有用 NRR 判"能不能上线"。
- [ ] 基线数据在项目第 1 天已采集(无法事后补)。

---

> **一句话收尾:** 指标不是仪表盘上的装饰,是续约谈判桌上的弹药,也是模式是否成立的体检仪。你算不清价值账,NRR<100% 时你连"为什么掉的"都说不清;你不盯毛利率和定制递减率,做着做着就退化成了咨询公司。**敢被检验,是 FDE 的立身之本——而检验的前提,是先把指标体系搭起来。**

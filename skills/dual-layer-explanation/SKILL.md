# 双层解释法

> 双层解释法——同一概念分别用小白版和专业版讲透，附术语对照与自测题（学习场景）。

## 何时使用

用户想学一个陌生概念、术语，或"好像懂了但说不清"时。

## 使用方法

把【】占位符替换为用户想学的概念或问题。

## Prompt 模板

把【】里的占位符换成你的信息，然后复制整段给 AI 使用：

```text
我想学习的是：【填写概念或问题】。
请分两层解释：
第一层，小白版。用生活化的语言和一个具体例子，让完全没有基础的人也能听懂。
第二层，专业版。使用准确术语，讲清核心机制、适用边界和常见误解。
最后请整理出：1. 列出小白说法与专业术语的对应关系；2. 我最容易理解错的地方；3. 3个用于检查我是否真正理解的问题。
```
